kxen 面向同时使用多个模型和账号，并需要让 Agent 长时间执行复杂工程任务的开发者。

## 解决的问题

普通聊天界面只管理一轮消息。复杂 coding 工作还需要管理目标、文件状态、命令、审批、子任务、并发、模型限额、恢复点和长期知识。kxen 把这些能力收敛为一个本地桌面运行时。

## 核心能力

- Workspace 和 Session 管理。
- 多 Provider、多账号和模型路由。
- Goal 生命周期和完成条件验证。
- QuickJS Dynamic Workflow。
- Subagent 和 Agent Teams。
- 文件、Shell、搜索、Browser、MCP 和 LSP 工具。
- Checkpoint、Rewind 和 Worktree。
- 项目规则、Skill、知识和记忆。
- 执行层 Safety、Approval 和审计事件。

## 非目标

- 通用聊天助手。
- 远程托管 Agent 服务。
- IDE 编辑器替代品。
- Windows、Linux 或 Intel Mac 客户端。
- 无审批的完全自治执行。
- 把 Provider 凭证上传到 kxen 服务。

## 当前发行状态

kxen 仍处于开发预览。仓库、下载、签名、自动更新和正式版本策略尚未对外开放。对外文档只描述已经存在的能力和冻结的平台边界，不把计划当作已交付功能。
