kxen 是一个专注 coding 场景的桌面 Agent Harness。它不替代模型，也不把任务转发给一个固定服务。它负责把多个模型、多个账号、多个执行角色和本地开发工具组织成可恢复、可审计的工作过程。

## 产品边界

| 维度 | 当前边界                           |
| ---- | ---------------------------------- |
| 平台 | macOS 14 及以上版本，Apple Silicon |
| 形态 | Tauri 2 单应用                     |
| 界面 | SolidJS 和 WKWebView               |
| 核心 | Rust                               |
| 模型 | 多 Provider、多账号、角色化路由    |
| 数据 | 本地优先                           |
| 发布 | 开发预览                           |

kxen 当前不提供 Windows、Linux、Intel Mac、CLI、TUI、公开服务端 API、云同步或插件市场。
