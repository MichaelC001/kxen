kxen 当前处于开发预览阶段。

## 已落地

- Workspace、Session 管理和持久对话分支树，包含编辑重发、重新生成、分支导航与谱系导出。
- 文本、文件、图片、命令、知识和语音 Composer。
- 44 个内置 Provider 条目、多账号、模型目录和角色路由。
- 13 家提供商的应用内 OAuth 登录，含授权码流、设备码流和 refresh 自动续期。
- 智谱、百炼、阶跃、豆包、千帆、腾讯的 Coding Plan 条目，以及 Vercel AI Gateway、Hugging Face 和 Ollama Cloud 网关条目。
- Goal、Workflow、Subagent、Agent Teams、Kanban 流水线和后台任务。
- 独立 Bot、每个 Bot 自己的交互式 self-builder、Routine、BotRun Recovery，以及 Direct 和 2 至 6 Bot Group 的 Bot-to-Bot 协作。
- 文件工具、Shell、LSP、MCP、Browser、Search 和 Schedule。
- Rules、References、Skills、Commands、Notes、Memory 和 History。
- Safety、Approval、Checkpoint、Rewind 和 Worktree。
- macOS、Windows 和 Linux 桌面安装包，内置自动更新通道。
- kxen 无头 server 和系统托盘的浏览器访问。

## 未开放

- 云同步、共享云电脑和托管执行。
- 插件市场和 Bot Marketplace。
- 多真人聊天、public Agent Card 和 external A2A endpoint。
- 面向第三方的稳定 API。

## 状态解释

- "已落地"表示能力已经存在于当前产品主路径。
- "未开放"表示用户现在不能把它当成可交付能力。
- Provider 和模型的实时可用性以应用中的账号状态和模型目录为准。
- Browser automation、Remote MCP 和自动知识沉淀默认关闭，不属于开箱即用能力。
- 开发预览不等于公开发行，安装资格单独见 [可用性](https://kxen.ai/overview/availability)。
