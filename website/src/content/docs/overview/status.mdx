页面状态描述当前开发预览，不等于公开发行承诺。

- Workspace、Session、消息流和持久化。
- Provider 认证、模型目录、账号管理和角色路由。
- Agent loop、Goal、Workflow、Subagent 和 Agent Teams。

- Remote MCP OAuth。

- Browser 自动化。
- 自动知识沉淀。

## 状态判定

- PASS 表示当前源码存在完整主链，并通过对应静态或自动检查。
- FAIL 表示实现、文档或门禁存在直接冲突。
- UNKNOWN 表示没有完成真实系统、Provider 或桌面交互验收。

功能页不会把 UNKNOWN 写成 PASS。
