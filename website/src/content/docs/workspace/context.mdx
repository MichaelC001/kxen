上下文是用户显式加入请求的信息，不等于整个 Workspace 的全部内容。

## 添加方式

- 在 Composer 中输入 `@` 搜索文件或目录。
- 使用附件菜单选择文件。
- 把文件或图片拖入 Composer。
- 直接粘贴图片或大段文本。

文件、目录和图片会显示为可移除的 chip。大段文本会折叠保存，在发送时恢复完整内容，避免输入框被长文本占满。

## 解析时机

附件在发送时解析。文件变化发生在添加 chip 之后时，实际发送内容以解析时的状态为准。外部文件必须经过原生文件选择授权，Workspace 内文件仍经过路径边界检查。

## 与自动上下文的关系

显式上下文由用户控制。Agent 仍可以在权限允许时通过工具继续读取相关文件。Rules、Notes 和 Memory 由知识系统根据作用范围和检索结果注入，不属于 Composer 附件。

## 控制规模

优先引用完成任务所需的最小文件集合。目录引用适合让 Agent 自行发现内容，但会增加后续读取范围。token 估算用于提示输入规模，不是模型端最终计费值。
