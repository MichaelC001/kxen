## Workspace

Workspace 是本地仓库的注册记录。它决定默认工作目录，并为项目配置、MCP、LSP、Hook、Knowledge 和 Worktree 提供边界。

Workspace 切换不是目录字符串替换。依赖工作目录的服务必须随 Workspace 生命周期更新。

## Session

Session 保存标题、目录、模型、父 Session 和消息历史。消息正文使用 JSONL 追加写，支持恢复、分叉和导出。

Session 可以:

- 重命名、置顶、排序和删除。
- 从指定消息分叉。
- 选择模型。
- 排队后续消息。
- 关联 Goal、Team、Schedule 和恢复点。

删除 Session 会进入废纸篓。删除前应停止活动 run，并清理关联状态。

## Composer

Composer 支持:

- 普通文本。
- 文件和目录引用。
- 图片附件。
- 大文本 paste chip。
- `@` 上下文触发。
- `/` 命令和 Skill 触发。
- `#` Knowledge 触发。
- Voice 输入。

附件在发送时解析。文件必须位于允许的 Workspace 边界内，URL 必须通过网络安全检查。

## 运行中消息

`send_when_running` 控制行为:

- `queue`: 默认值。等待当前 run 完成。
- `interrupt`: 取消当前 run，然后处理新消息。

Abort 优先于审批、等待和长命令。每个 run 必须发出完成或错误终态，不能静默结束。
