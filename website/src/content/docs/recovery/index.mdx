这三个能力解决不同问题:

- [Checkpoint](https://kxen.ai/recovery/checkpoint) 记录可恢复状态。
- [Rewind](https://kxen.ai/recovery/rewind) 回到指定消息。
- [Worktree](https://kxen.ai/recovery/worktree) 隔离并行修改。

它们都涉及文件状态，但不会替代用户自己的 Git 提交和分支管理。
