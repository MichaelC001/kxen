首次使用只需要完成三个步骤:

1. 确认 [系统要求](https://kxen.ai/getting-started/requirements)。
2. 注册 [第一个 Workspace](https://kxen.ai/getting-started/first-workspace)。
3. 完成 [第一个 Session](https://kxen.ai/getting-started/first-session)。

当前发行资格单独见 [可用性](https://kxen.ai/overview/availability)。首次使用的目标是确认 Workspace、Provider、模型和基础工具形成完整闭环。
