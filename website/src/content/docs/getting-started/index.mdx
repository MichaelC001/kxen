首次使用按应用 Settings 中的检查清单完成:

1. 按 [可用性](https://kxen.ai/overview/availability) 下载并安装最新版本。
2. 确认 [系统要求](https://kxen.ai/getting-started/requirements) 和安全默认值。
3. 注册 [第一个 Workspace](https://kxen.ai/getting-started/first-workspace)。
4. 连接至少一个 Provider，并确认账号状态。
5. 检查 thinking、planning、execution、review 和 research 的角色路由都有可用落点。
6. 完成 [第一个 Session](https://kxen.ai/getting-started/first-session)。

Browser automation、Remote MCP 和自动知识沉淀保持默认关闭，只有理解数据边界后再逐项开启。首次使用的目标是确认 Workspace、Provider、模型、路由和基础工具形成完整闭环。

基础 Session 闭环稳定后，如果需要把同一工作定义长期复用，再从 [创建与完善 Bot](https://kxen.ai/bots/build) 与新 Bot 自己的 self-builder 对话。Bot 不会继承当前 Session 或构建对话的临时权限，Owner 仍需检查并授予精确 capability 和 resource grant。
