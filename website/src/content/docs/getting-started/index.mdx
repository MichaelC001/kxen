kxen 当前处于开发预览，没有公开安装包。正式开放后，从本节完成安装、Provider 准备和第一个 Session。

## 顺序

1. 查看[可用性](/getting-started/availability)。
2. 阅读[系统要求](/getting-started/requirements)。
3. 创建[第一个 Session](/getting-started/first-session)。
4. 配置 Provider 和模型路由。

首次运行前先确认 Provider 官方客户端已经完成登录。kxen 读取可用的本地凭证，不要求把密钥写进 Workspace。
