## 运行平台

- Apple Silicon Mac。
- macOS 14 或更高版本。
- 可用的 WKWebView。

Intel Mac、Windows 和 Linux 不在当前支持范围。

## 开发工具链

- Rust stable，支持 edition 2024。
- Node.js 24。
- pnpm 11.15.1。
- Xcode Command Line Tools。
- Tauri 2 所需的 macOS 开发组件。

## 可选工具

- `rust-analyzer`
- `typescript-language-server`
- `pyright-langserver`
- `gopls`
- Google Chrome

缺少可选 LSP 或 Chrome 时，对应工具降级为不可用，不影响基本 Session 和模型调用。

## Provider 准备

Provider 账号和模型可用性由本机凭证、API 配置和实时模型目录共同决定。不要把凭证写入仓库、文档或 Shell 历史。
