| 快捷键  | 动作                         |
| ------- | ---------------------------- |
| `Cmd+N` | 创建新 Session               |
| `Cmd+W` | 关闭当前 Session             |
| `Cmd+,` | 打开设置                     |
| `/`     | 在文档站侧栏中聚焦过滤输入框 |

在非 macOS 键盘事件中，应用也接受对应的 `Ctrl` 组合，但正式支持平台仍是 macOS。

## 运行中的 Session

当当前 Session 正在运行时，第一次 `Cmd+W` 只进入确认状态。在 4 秒内再次按下 `Cmd+W` 才会删除 Session。

删除成功后，Session 文件进入系统废纸篓。该行为不会静默停止并删除一个活动 run。

## Composer

Composer 内的 `@`、`/` 和 `#` 是内容触发器，不是全局快捷键:

- `@` 添加文件、目录或其他上下文。
- `/` 调用命令或 Skill。
- `#` 检索或沉淀 Knowledge。
