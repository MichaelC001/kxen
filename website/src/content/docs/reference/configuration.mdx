kxen 使用 TOML 配置。用户配置位于 macOS home 下的 `.config/kxen/config.toml`。受信任 Workspace 可以通过根目录中的 `.kxen/config.toml` 覆盖用户配置。

项目配置只在 Workspace 已被信任时加载。项目级表项覆盖同名用户级表项，Hook 列表按事件追加。

## 完整示例

```toml
send_when_running = "queue"

[limits]
global_concurrent = 8

[limits.providers.anthropic]
concurrent = 2
rpm = 30

[roles.execution]
provider = "xai"
model = "grok-build-0.1"
account = "work"
fallback = "research"

[statusline]
items = ["workdir", "git", "goal", "tasks", "tokens", "ctx", "model"]

[voice]
engine = "apple"
fallback = ["openai"]
locale = "zh-CN"
transcribe_model = "whisper-1"

[embedding]
provider = "ollama"
model = "nomic-embed-text"
base_url = "http://localhost:11434"

[search]
engine = "auto"
google_cx = ""
searxng_url = ""

[custom_providers.example]
base_url = "https://api.example.com/v1"
protocol = "openai"
models = ["example-model"]
capabilities = ["text"]

[[hooks.pre_tool_use]]
matcher = "exec|write|edit"
command = "scripts/check-tool.sh"
```

## roles

内置角色为 thinking、planning、execution、review 和 research。

每个角色支持:

- `provider`: Provider ID。
- `model`: 模型 ID。
- `account`: 可选账号名。
- `fallback`: 可选降级角色。

模型 ID 以应用中的实时目录为准。静态文档不承诺 Provider 始终提供某个模型。

## limits

- `global_concurrent`: 所有模型调用共享的全局并发上限，默认值是 8。
- `limits.providers.<id>.concurrent`: Provider 并发上限。
- `limits.providers.<id>.rpm`: 每个账号的 60 秒请求上限。

Provider 的多个账号共享 Provider 并发池，RPM 按账号分别记账。

## send_when_running

- `queue`: 默认值。新消息进入当前 Session 的 pending queue。
- `interrupt`: 取消当前 run，再处理新消息。

## hooks

Hook 事件支持一个或多个命令。`matcher` 是工具名正则，省略时匹配全部工具。Hook 不能绕开执行层 Safety 和 Approval。

## 凭证

API key、OAuth access token 和 refresh token 不写入 TOML。凭证由本地认证存储管理，项目仓库必须保持零明文。
