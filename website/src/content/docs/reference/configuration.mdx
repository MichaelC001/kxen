kxen 使用 TOML 保存非敏感配置。

## 配置层级

- 用户配置: `file:///Users/you/.config/kxen/config.toml`
- 项目配置: `file:///path/to/workspace/.kxen/config.toml`

项目配置只在 Workspace 已信任时加载。项目级表项覆盖同名用户级表项，Hook 列表按事件追加。

## 示例

```toml
send_when_running = "queue"

[limits]
global_concurrent = 8

[limits.providers.anthropic]
concurrent = 2
rpm = 30

[roles.execution]
provider = "xai"
model = "grok-build-0.1"
account = "work"
fallback = "research"

[voice]
engine = "apple"
fallback = ["openai"]
locale = "zh-CN"
transcribe_model = "whisper-1"

[embedding]
provider = "ollama"
model = "nomic-embed-text"
base_url = "http://localhost:11434"

[search]
engine = "auto"

[custom_providers.example]
base_url = "https://api.example.com/v1"
protocol = "openai"
models = ["example-model"]
capabilities = ["text"]
```

## 资源限制

- `global_concurrent`: 所有模型调用的全局并发上限，默认值为 8。
- `limits.providers.<id>.concurrent`: Provider 并发上限。
- `limits.providers.<id>.rpm`: 每个账号的 60 秒请求上限。

多个账号共享 Provider 并发池，RPM 按账号分别记录。

## 运行中消息

- `queue`: 新消息进入等待队列。
- `interrupt`: 取消当前 run 后处理新消息。

## Hook

Hook 可以在工具事件上运行命令，并通过 matcher 限定工具名。Hook 仍受 Workspace 信任、Shell Safety 和 Approval 约束。

## 凭证

API key、OAuth access token 和 refresh token 不写入 TOML。配置文件只引用 Provider、账号名、模型和非敏感端点信息。
