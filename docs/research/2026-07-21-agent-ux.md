# Agent UX 调研附录（2026-07-21，6 路并发调研原始结论）

> 每条的来源已在调研时核实。此文件是 P0 plan 的证据底座，后续修订 plan 先查这里。

## 1. Composer @ 引用（Cursor/Zed/Cline/Continue 源码级）

- 触发：裸 `@`，取光标前最右一个，前界行首/空白/`([{`，后界非空白；支持 `@file <query>` 两级（Zed completion_provider.rs L2073-2145）
- 防抖 200ms（Cline ChatTextArea L779-806 验证值）；键盘：上下移动、Enter/Tab 确认、Esc 关闭、mention 尾部 Backspace 整 chip 删除
- chip 数据结构：Zed `MentionUri` 枚举（File/Directory/Symbol/Fetch/GitDiff/Skill/...）惰性解析；同名 chip 标签升级末两级路径消歧
- 注入格式（Cline 式 XML）：正文改写 `'path' (see below for file content)`，尾部 `<file_content path="...">...</file_content>` 按序拼接、去重
- 大文件降级（Zed outline.rs）：16KB 阈值转符号大纲 `[L12-45]`，兜底前 1KB；建议加单文件 64KB / 单消息 200KB 硬 cap（Cline 无 cap 是已知上下文膨胀教训）
- @Docs（Continue）：embedding 检索 nRetrieve=30 -> rerank -> nFinal=15；@Web 默认 6 条

## 2. Skills / commands（Claude Code/Kimi Code/OpenCode 源码级）

- frontmatter 开放标准（agentskills.io）：`name`（<=64，小写+连字符，与目录同名）+ `description`（<=1024）必填；`allowed-tools` 是实验字段且语义各家不一致（只解决"当轮免审批"）——v1 不做
- Claude 扩展子集：`when_to_use`、`arguments`、`disable-model-invocation`、`user-invocable` 四字段足够
- 清单注入：description 截断 250 字符（kimi-code LISTING_DESC_MAX）
- 双触发：显式 `/name`（activate -> 作为用户消息进入）与隐式（Skill 工具）统一包装 `<kxen-skill-loaded name trigger dir args>`；递归深度 cap 3；工具描述写明"同 args 已加载禁止重调"
- 挂载生命周期：持续整个 session（消息形式进入上下文）；compaction 预算：每 skill 5000 token、全部共享 25000 token（Claude 数值）
- 参数展开：`$ARGUMENTS`、`$ARGUMENTS[N]`、`$N`、`$name`，无占位符时尾部追加 `ARGUMENTS: <raw>`（kimi-code parser.ts:176-214 同款）
- 目录约定：项目 `.kxen/skills/` + 用户 `~/.kxen/skills/` + 兼容 `.agents/skills/` 吃生态；扁平 .md 与目录型 SKILL.md 并存；扫描深度 cap 8；项目覆盖全局，同名 first-wins
- commands（OpenCode）：`.md` 文件名=命令名，嵌套目录变 `/team/review`，模板支持 `$ARGUMENTS`、`!`cmd``、`@file`

## 3. 图片多模态（四家 provider 2026 现状）

- anthropic：base64 source，单图 10MB/8000px/100 图，推荐长边 1568px
- openai：image_url data URL，单图 20MB/500 图，detail low|high|auto
- xai：OpenAI 兼容但只收 jpg/png，单图 20MiB，448px tile 计费 <1792 tokens/图
- kimi：只收 base64 或 ms:// 文件引用（不收公网 URL）；kimi-for-coding 订阅端点标 image_in:false（行为不稳定），fallback 目标 kimi-k3/k2.6
- 降级：capability 驱动 UI（无 image_in 禁用 chip）+ vision fallback（用订阅内首个 image_in 模型生成 <=200 字描述注入）；fallback 不可用时明确报错不静默丢图
- 统一预处理：长边 <=1568px、>5MB 转 JPEG q85、WebP/GIF 给 xAI 前转 PNG
- 消息类型：content 改 Vec<Part>，Part=Text|Image{media_type,data(base64)}；全链路只 base64 不做 URL 分支

## 4. statusline 与设置页（Claude Code/Zed/Cursor/LobeHub）

- statusline 走固定段+开关（对齐 Zed 白名单），不做 Claude Code 的 shell 脚本；`[statusline] items=[...]` 每段 bool
- 单行 cap 120 列右截断；刷新 300ms debounce + 事件驱动不轮询；git 段进程内缓存 5s
- ctx 进度条 10 格，阈值 <70 绿 / 70-89 黄 / >=90 红（Claude 官方示例）
- 状态栏只放 3 个数字：ctx%、session tokens、当前 model；明细收进设置页用量区
- 设置页左导航 5 区按频率：通用 -> 模型路由 -> 用量与统计 -> 知识库 OKF -> 高级（hooks/limits）
- 角色路由：固定枚举 chat/thinking/execution/subagent/title/compress + default 行，四列表格 role/provider/model/fallback；mrm.rs:57 静态兜底链搬进 config `roles.<role>.fallback`
- merged view（用户层+项目层合并）展示，写入只落用户层（Zed UserSettings/ProjectSettings 模式）；密钥只进 Keychain

## 5. 知识沉淀（Claude Code/Cursor/Windsurf/ChatGPT/Letta）

- 双库分层：`.agents/rules/*.md`（用户写，入 git 共享）+ `.kxen/memory/`（agent 写，gitignored 本地）
- MEMORY.md 索引 + topic 文件结构（Claude 独有且验证）；索引 cap 200 行/25KB，超限写回返回 error 强制 agent 重写收敛（零代码自平衡）
- 写入三通道：composer `#` 前缀快捷写（弹层选 project/global）+ 会话内 agent 判断 + `/done` 会话结束 smol 角色 distillation 出 diff 用户确认后落盘
- 不做 silent auto-write（Windsurf/Cursor memories 不可审计的教训）；无 TTL 衰减先例；三件套：写入 merge + 超 cap 强制重写 + doctor 定期提议 trim
- 无向量库/RAG 先例（五家全部 plain markdown）；memory 元数据用 HTML 注释（加载前 strip）
- cap 事实值：rule 单文件 <500 行（Cursor）、全局 rules 12000 字符（Windsurf）
- /done 先例：Letta sleep-time agent 后台复盘 consolidate；CC/Cursor/Windsurf 均无内置，属空白点

## 6. 统计 / abort / checkpoint（opencode/Cline/Aider/Claude Code 源码级）

- 统计形态：消息 footer 徽标 `1.2k tok · 28 tok/s`，hover 详情 {prompt/completion/ttft_ms/duration_ms/model}；composer 右下实时预估 input tokens（>80% 橙 / >95% 红）
- abort 共识：单 session 一个 cancel 通道 + 中断点统一清扫（进行中的 tool call 落库 interrupted 终态，不留 pending）+ 子代理独立 token 父级联 + cancel 后状态机进终态禁止自动重试（Cline 的 hook 期 abort 自动重启是反面教材）
- checkpoint 共识：shadow git（bare repo 存全局数据目录，--git-dir+--work-tree 不污染项目）+ 文件编辑工具成功后 commit + 粒度绑 messageID + 三档 restore（code/conversation/both）+ unrevert
- 容量：每 session 100 个滚动（Claude）、全局 30 天清理、单文件 diff 上限 2MB（opencode）、排除 node_modules/target
- bash/shell 造成的改动不进 checkpoint（Claude 限制，文档明示"checkpoint 是 session 级 undo 不替代 git"）
- Aider 另类：直接用项目 git 真实 commit + /undo revert——简单但污染用户历史，不采用
