# kxen 人工走查清单（UI 细节对齐验收）

按序过一遍；每项给「操作 -> 预期」。发现不符合按编号报。

## A 交互正确性

- A1-1 文本选择：拖动选中 assistant 回复文字 -> 可选中；点击会话行/按钮/开关 -> 不出现选中态（点击即动作）。
- A2-1 会话行相对时间：会话列表每条右侧显示「刚刚 / N 分钟前 / 昨天 / N 天前」。
- A2-2 置顶：hover 会话行点 pin -> 该行跳到组首并带 pin 图标；再点取消。
- A2-3 重命名：双击会话标题 -> 行内输入框，Enter 保存；Esc 取消。重启 app 后保持。
- A2-4 拖拽排序：按住会话行拖到另一条上 -> 顺序变化且重启后保持。
- A2-5 运行指示：某会话有 run 进行中 -> 该行左侧绿色脉冲点。
- A3-1 删除确认：点会话行 X -> 变成 确认/取消 两键，确认才删。

## B 消息区

- B4-1 复制：hover 任意消息点复制图标 -> 图标变勾，剪贴板有全文。
- B4-2 重新生成：hover assistant 消息点重跑 -> 自动重发上一条 user 消息。
- B4-3 编辑重发：hover user 消息点铅笔 -> 行内编辑框，改字提交 -> 自动开分叉会话（列表出现「分叉: …」）且内容已发送。
- B5-1 assistant 尾部：显示 模型名 + in/out tokens + TTFT + 耗时 + tok/s。
- B5-2 代码块：hover 代码块右上角「复制」-> 变「已复制」。
- B6-1 草稿：s1 输入一半切到 s2（空）再切回 s1 -> 草稿原样恢复；发送后清空。

## C 体系件

- C7-1 Cmd-N -> 新会话草稿态；Cmd-W -> 当前会话被删并切下一条；Cmd-, -> 进设置。
- C8-1 设置 -> 高级 -> 导出诊断包 -> ~/Downloads 出现 kxen-diagnostics-*.md（providers/mrm/config 三段）。
- C9-1 通知中心：statusbar 铃铛有未读角标（teammate 来信/cron 触发后），点开有时间线；全部已读/清空可用。

## D 视觉基线

- D10-1 空态统一：无会话 / 无通知 / 无知识条目 / 无隔离树 -> 都是「图标 + 一行灰字」同一形态。
- D10-2 间距：列表行高、卡片内边距、区块间隔整页一致（无肉眼突兀的跳跃）。

## 遗留已知限制（非缺陷）

- anthropic 订阅凭证需在 keychain 弹窗点「始终允许」或重登 claude（启动不再自动弹）。
- token refresh-on-401 未实现（refresh_token 已存未用）。
- 拖拽排序与置顶同组时，置顶永远排前（手动序只对非置顶生效）。
